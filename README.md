# Minecraft Bot

Этот проект нужен, чтобы на твоём ПК запустился бот для Minecraft, который заходит на сервер, отвечает в чате, исследует территорию, добывает дерево и руду и делает базовые действия в игре.

## Что умеет бот
- заходить на Minecraft-сервер;
- отвечать в чате;
- искать ближайшее дерево и добывать его;
- искать ближайшую руду и добывать её;
- исследовать территорию вокруг себя;
- строить простой блок рядом с собой;
- использовать локальную ИИ-модель Ollama для общения.

## Что нужно сделать по шагам

### 1) Установить Node.js
Скачай и установи Node.js 18+ с официального сайта:
https://nodejs.org/

После установки проверь, что всё работает:

```bash
node -v
npm -v
```

### 2) Установить Ollama
Скачай Ollama отсюда:
https://ollama.com/

После установки открой терминал и запусти:

```bash
ollama pull llama3.1:8b
```

Если хочешь проверить модель:

```bash
ollama run llama3.1:8b
```

Это нужно, чтобы бот мог отвечать через локальную ИИ-модель.

### 3) Склонировать/открыть проект
Открой папку проекта у себя на компьютере, например:

```bash
cd путь/к/проекту
```

### 4) Установить зависимости
В терминале запусти:

```bash
npm install
```

### 5) Создать файл настроек
Создай файл `.env` на основе шаблона:

```bash
copy .env.example .env
```

Если ты на Linux/macOS:

```bash
cp .env.example .env
```

### 6) Настроить `.env`
Открой `.env` и измени параметры под себя.

Пример:

```env
HOST=localhost
PORT=25565
USERNAME=BotName
VERSION=1.20.4
AUTH=offline
PASSWORD=
AUTO_SAY_HELLO=false
COMMAND_PREFIX=!
LLM_PROVIDER=ollama
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3.1:8b
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4o-mini
RECONNECT_DELAY_MS=5000
```

Что значат поля:
- `HOST` — IP или домен сервера
- `PORT` — порт сервера, обычно `25565`
- `USERNAME` — ник бота
- `VERSION` — версия сервера, например `1.20.4`
- `AUTH` — `offline` для обычного входа, или `mojang` / `microsoft` для аккаунта
- `PASSWORD` — пароль, если используешь аккаунт
- `LLM_PROVIDER=ollama` — локальный ИИ
- `OLLAMA_BASE_URL=http://localhost:11434` — адрес Ollama
- `OLLAMA_MODEL=llama3.1:8b` — модель, которую ты скачал

### 7) Запустить бота
В терминале:

```bash
npm start
```

На Windows можно просто запустить файл `start.bat`.

### 8) Если бот не подключается
Проверь:
- сервер запущен;
- верный IP и порт;
- `VERSION` совпадает с версией сервера;
- Ollama запущен и модель скачана;
- `AUTH` и `PASSWORD` указаны правильно, если это не `offline`.

## Что умеет бот
- подключаться к серверу Minecraft;
- отвечать в чате;
- реагировать на команды `!help`, `!ping`, `!hello`, `!status`;
- использовать локальную AI-модель Ollama;
- после запуска держать соединение и переподключаться при обрыве.

## Важно
Бот работает с Java Edition сервером. Если хочешь вход через реальный аккаунт, задавай `AUTH` и `PASSWORD` правильно. Файл `.env` не надо выкладывать в интернет.

## Примечание для Windows
Самый простой способ:

1. открыть папку проекта;
2. запустить `start.bat`;
3. дождаться установки зависимостей;
4. бот начнёт запускаться.

Если хочешь, я могу ещё сразу сделать версию с “умным” ботом, который умеет ходить по миру, следовать за игроком и выполнять простые игровые команды, а не только отвечать в чате.
